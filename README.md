# Biker's Brewing Café — Pro Website
Static production-ready frontend with centralized JSON data.

Run locally: `python -m http.server 8000`
Deploy: upload the complete folder to Replit/static hosting.

Update business details in `data/business.json`.
Update menu in `data/menu.json`.
Update gallery images in `data/gallery.json`.
Update review excerpts in `data/reviews.json`.

The reservation form has validation and a success state but does not store or confirm bookings. Connect a real backend/API before live reservations.

No menu prices were invented; unavailable prices display “Price available at café”.
